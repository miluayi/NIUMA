# V2 功能保留矩阵

本矩阵是 V3 UI 调整的硬约束：设计可以改变入口位置、信息层级与控件形态，但不得删除、弱化为不可达，或改变下列功能的业务语义。当前 `03_ui_design` 的方案 B C++/QSS 原型是设计基线，页面占位不等于功能废弃。

| V2 功能域 | 必须保留的能力 | V2 证据 | V3 设计约束 |
|---|---|---|---|
| 全局壳层 | 首页、任务、周期、资料、成果、统计、回收站、设置 8 个入口 | `ui/MainWindow.cpp:170-197` | 8 项导航固定保留；采用方案 B 的 184px 侧栏、70px 标题栏、顶栏操作与设置入口 |
| 任务 | 新建、列表、筛选、详情、编辑、完成、移入回收站、恢复后的刷新 | `ui/MainWindow.h:57-61`，`ui/TaskListView.h`，`ui/TaskDetailView.cpp:1034` | “新建任务”始终可见；列表四态与键盘路径不能取消 |
| 周期任务 | 模板创建、编辑、生成实际任务、忽略本次提醒 | `ui/MainWindow.h:64-67`，`ui/MainWindow.cpp:734-757` | 周期任务保留一级入口与首页提醒；禁用/受限必须给出原因和下一步 |
| 参考资料 | 创建、查看、编辑、删除、筛选、目录关联 | `ui/ReferenceView.h`，`ui/ReferenceDetailDialog.cpp:318-340` | 资料入口、筛选和详情/编辑流程不能并入任务后消失 |
| 年度成果 | 成果维护、年度/重点标记、导出总结 | `ui/AchievementView.h`，`ui/AchievementDialog.cpp:217-221` | 独立一级入口和导出动作保留 |
| 统计 | 统计页刷新与可读数据替代 | `ui/MainWindow.cpp:449-454`，`ui/StatsView.h` | 统计数据不得只用颜色或图形表达 |
| 回收站 | 查看、恢复、彻底删除、清空、30 天清理 | `ui/RecycleBinView.h`，`ui/RecycleBinView.cpp:634-646` | 危险操作保持二次确认与可理解的后果提示 |
| 设置与维护 | 工作目录、备份、恢复、扫描导入、初始化后的引导 | `ui/MainWindow.h:68-73`，`ui/MainWindow.cpp:760-872` | 设置中心保留；顶栏只增加快捷入口，不改变原有语义 |
| 全局行为 | 最小化、最大化、关闭、状态栏、刷新 | `ui/MainWindow.cpp:153-243` | 生产版采用方案 B 自绘窗口壳；F5/顶栏刷新均保持可达，并回归窗口/焦点行为 |

## 本轮设计变化边界

- 仅增加方案 B 已定稿的可视入口：顶栏刷新、搜索、新建和导航历史；不得借迁移新增业务语义。
- 不改数据库 schema、工作目录命名、文件归档、备份格式、任务状态枚举或服务层。
- 新增入口在生产接线时必须复用原有用例/服务，而不是创建平行实现。
- 每阶段的功能保留必须通过隔离 fixture 的 MCP E2E 方案和执行记录；浏览器适配面用 Playwright MCP，原生 Qt Widgets 用 LazyTesting/桌面自动化 MCP。测试后调用可用 `/simplify` 并复测。
