# S07 参考资料 E2E 与契约测试方案

## 范围与边界

复用 v2 Qt5 Widgets 的资料数据库、编号、工作目录、附件复制和物理删除链路；本阶段只迁移方案 B 的页面、表单和详情样式，不变更 schema、目录结构或删除语义。

## 可观察验收场景

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| S07-C01 | 空态和筛选 | 空资料页显示独立空态；命中与无结果能往返。 |
| S07-C02 | 新建表单 | 560px 双列弹窗含名称、编号、来源、标签、96px 说明和附件区；Esc 不创建。 |
| S07-C03 | 创建资料与目录 | 通过弹窗创建资料后生成编号、数据库行及隔离工作目录。 |
| S07-C04 | 列表横滚 | 无纵向溢出、存在横向溢出时，资料表格把纵向滚轮转为横滚。 |
| S07-C05 | 编辑、详情与删除 | 编辑持久化；详情显示标题/基本信息；删除确认取消保持数据库与目录，确认后物理删除二者。 |
| S07-E01 | 桌面回归 | pywinauto 用独立 Data 启动无框主程序，验证导航、快捷键、对话框与窗口操作。 |

## 执行边界

- `NiumaV3ReferenceContractTest` 只使用 `NIUMA_TEST_ROOT` 下的 fixture；创建和删除的目录均位于该根目录。
- 先运行专用 CTest，再运行完整 CTest 和桌面 E2E。
- 若 BitBlt 截图仍不可用，只保存结构化 E2E 证据；`page-3` 像素对照继续留给 S12，不能以结构化结果替代。
