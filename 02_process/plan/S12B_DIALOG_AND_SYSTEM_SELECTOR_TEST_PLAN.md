# S12-B 通用确认框与系统选择器测试计划

日期：2026-09-23（Asia/Shanghai）  
状态：结构化确认框子门完成；系统选择器和像素/DPI 门仍阻断。

## 问题与结果

各业务合同已在隔离 fixture 中覆盖任务、资料、周期、回收站和设置的主要确认分支，但此前用直接 `accept/reject` 关闭模态框，未验证所有这些路径共同复用的 `StyledMessageBox` 按钮语义。本切片为该组件建立独立、无业务副作用的 Qt 合同测试。

范围仅限 `StyledMessageBox`。不调用真实删除、恢复、初始化、文件选择或生产 `Data`；不重新设计方案 B。
