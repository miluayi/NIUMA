# 方案 B：NIUMA v2 全链 UI 基线

方案 A、C 的模拟程序已退出；方案 B 是唯一继续迭代的设计草案。B 以
`D:\project\05_workspace_v2` 的实际实现为唯一排版基线，使用同一套假数据在独立 Qt 预览程序中呈现，供后续“改一处 → 重启 → 交互检查”循环使用。

## 产品与技术栈

- 产品：NIUMA 铁军牛马任务日志，本地离线个人工作台。
- 运行栈：Qt 5.15 Widgets、C++17、CMake、SQLite；B 只模拟 UI 和交互，不连接生产数据库。
- 设计入口：v2 的 `03_ui_design/index.html` 与 `qt_implementation_guide.md`，最终视觉以 Qt QSS 能稳定复现的实现为准。
- 主窗体：1440×900，最小 940×580；自定义标题栏 52px，侧栏 220px，底部状态栏 36px。

## 页面链路

1. 首页：今日专注 → 进行中任务 → 周期任务提醒 / 本月概览。
2. 任务管理：页面标题与说明 → 双行筛选 → 任务表格 → 分页。
3. 周期任务：标题与新建入口 → 周期模板表格。
4. 参考资料：标题、打开目录、新建资料 → 来源/标签筛选 → 资料表格。
5. 年度成果：年份与导出 → 成果统计卡 → 成果表格。
6. 统计：任务统计 / 趋势图 / 热力图三个标签页。
7. 回收站：批量选择、恢复、彻底删除、清空、刷新 → 回收站表格。
8. 设置中心：工作目录、字典管理、导出设置、数据管理、关于、初始化软件。

## 弹窗链路

- 新建任务、编辑任务：两列表单、任务说明、附件区、保存/取消。
- 任务详情：任务标签、标题操作、四列基础信息、说明、附件、备注、历史、成果。
- 新建/编辑周期任务：模板名称、分类、周期类型、办理人、提醒时间、启用状态。
- 新建/编辑参考资料：名称、编号、来源、标签、说明、附件区。
- 参考资料详情：基本信息、说明、打开资料目录。
- 登记成果：工作内容、数量、金额、说明、年度/重点勾选。
- 扫描导入：扫描提示、预览表格、确认导入。
- 删除确认：危险提示、取消、确认删除。

## 交互契约

- 任务分类固定为催 / 查 / 报 / 办，并使用各自语义色。
- 重点任务使用名称前缀 `【重点】`；今日专注使用 `☆/★` 双向同步，最多 3 项。
- 任何任务行单击打开任务详情；资料行单击打开资料详情。
- Enter 保存，Esc 取消，Delete 删除，Ctrl+N 新建任务，Ctrl+F 搜索，F5 刷新。
- 列表必须覆盖空态、加载态、异常态；筛选无结果和数据库为空要区分。
- 方案 B 只替换视觉与交互原型，不改 v2 的功能语义、状态转换和文件目录约束。

```powershell
04_program\tools\run_preview.ps1 -SchemeB
```
